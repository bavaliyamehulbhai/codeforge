# CodeForge MERN Stack 🚀

A professional-grade online compiler and snippet manager built with the MERN stack.

## 📁 Modular Structure

This project is organized into two independent directories. To run the full application, you should start both the **frontend** and **backend** separately.

### 1. Backend Setup (API & Database) 🛠️
1. `cd backend`
2. `npm install`
3. `npm run dev` (Runs on http://localhost:5000)

### 2. Frontend Setup (React UI) ⚛️
1. `cd frontend`
2. `npm install`
3. `npm run dev` (Runs on http://localhost:3000)

## 💎 Features
- **Project Templates**: Launch C++, Python, and JS projects instantly from the Home page.
- **JWT Authentication**: Secure user management via a custom Node/Express backend.
- **MongoDB Persistence**: Persistent snippet storage using Mongoose.
- **Premium Design**: Glassmorphism UI with HSL-based technical theme.

## 📜 Project Map
- `backend/`: Node.js/Express API with MongoDB.
- `frontend/`: React/Vite/TypeScript UI.
- `.env`: Ensure you have correct environment variables in both `frontend/` and `backend/`.
